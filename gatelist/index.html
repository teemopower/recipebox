gatelist

decide where AI agents can act ⛩

A browser extension for IT admins. Pick the AI agents (Claude in Chrome, the ChatGPT extension, Copilot in Edge, Gemini auto browse), pick the sites, and Gatelist writes the Chrome and Edge policies: Windows .reg, JSON, macOS .mobileconfig or GPO/Intune values.

get it for Microsoft Edge

how it works

Extension agents are limited with ExtensionSettings runtime_blocked_hosts / runtime_allowed_hosts. Copilot uses BrowsingWithCopilotAllowList / BlockList. Gemini auto browse uses GeminiActOnWebSettings. After deploying, check chrome://policy or edge://policy.
