field mask

your info, blurred for the bots 🙈

AI agents and screen shares see what's on your screen. Field Mask blurs passwords, card numbers, IDs and bank details before they do. Flip on agent mode (or press Alt+Shift+M) before an AI agent drives a tab, then hold Alt to peek.

the honest part

Field Mask changes what's shown on screen, which is what screenshot-based agents, screen shares and recordings capture. It can't stop software that reads a page's code directly, and it isn't a password manager or antivirus.
